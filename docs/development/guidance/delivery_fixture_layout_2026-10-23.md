## What the preflight verifies

`preflight` requires an absolute, nonsymlink layout root and an independent
layout-contract pin. It rechecks all predecessor relationships and file bytes,
exact file membership, the module map, expected runtime declaration and false
qualification flags. Extra bytecode, substituted source, symlinks and namespace
shadowing reject. Before source lookup it rejects any cached project/learner/
fixture module, including `ace.*`, `experiments.*` and the dynamic generator name.
An existing import must be handled by starting a fresh process; it is not
silently removed or accepted because its `__file__` looks plausible.

Explicit standard `FileFinder` objects inspect source specs using only the
declared directories. No loader's `exec_module` is called. Global path hooks,
`sys.path_importer_cache`, `sys.path` and `sys.meta_path` are not used to import
the inspected sources or changed. The resulting receipt describes current
source bytes and explicit source-only resolution. It does **not** install an
enforcing finder for a later execution, authenticate already imported numerical
dependencies, or prove that a future runner uses this path order.

The exact original B dependency versions and Python3.11 requirement are contract
declarations. This preflight imports none of those numerical dependencies and
does not qualify the Mac runtime. The independent exact-runtime replay gate
remains open pending the separately requested08approval.
