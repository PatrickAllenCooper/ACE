# Prospective fixture location derivation — October 8, 2026

This is the first narrow location interface for original B development fixtures.
It prepares source bytes only. It does not execute fixtures, original collection
or training, qualify imports/runtime, or change the frozen replay package/job03.
The original study and all accepted A/C/F artifacts remain unchanged.

## Exact original and derived sources

`prepare_delivery_prospective_fixture_locations.py` requires an independently
pinned original source-closure JSON, frozen revision45ebeb89 and registration
e9fb12aa. It verifies all24 project and19 learner source objects against that
captured closure before creating output. The two fixture originals additionally
have hard-coded original registration source digests. Metadata and source are
hashed and parsed from the same captured bytes; original entry points are not
imported or executed. Complete scientific artifacts are not inputs to this tool.

The model fixture's `PROJECT` and `SOURCE` declarations become explicit children
`project` and `source` of the required `ACE_DELIVERY_FIXTURE_ROOT` environment
variable. There is no default personal directory. These are new location
expressions, not historical source identities. Exactly those two right-hand
expression spans change; all other original bytes survive, including every
function, class, assertion, helper import and optimization/calibration rule.
AST comparison independently rejects changes outside the location expressions.
The UTF-8 byte offsets also support multiline expressions.

The IO fixture remains byte-identical. It still imports the model fixture by its
original module name. Both derived fixture files therefore need a shared fixture
directory in any later reviewed import layout. Original worker and guard files
are not modified, expected source hashes are not replaced, and no original
acceptance receipt is reserialized.

Output is a new exclusive private directory containing two originals, two
prepared fixture sources and a contract. The contract binds original closure,
revision, registration, original/derived file hashes, the two exact expression
changes, and remaining gates. It deliberately contains original private location
expressions and is not an anonymous public artifact. Custody uses the previously
reviewed descriptor-relative/private macOS output helpers. Their existing tests
are not repeated here. Trusted current-UID/root and ACL limits remain as stated
in delivery_publication_snapshot_2026-10-08.md.

## Execution remains unqualified

This preparation must not be advertised as an executable anonymous training
package. Original fixture imports precede their location declarations; no new
import-authentication guard is inserted. Before any later execution, supply an
authenticated project/learner/import layout, reject incompatible cached modules
before original fixture imports, require an explicit absolute layout root and
the actual exact B dependency environment, and review the invocation/resource
and fixture authorization. The prepared files alone establish none of these.

The model fixture includes development optimizer parity computations and
structural-response construction; executing it would do more than inspect
metadata. This turn never executes it. The unchanged IO tests contain charged
failure and heldout-access assertions; source preservation is not evidence that
those checks executed in a relocated runtime. Batch/audit/collection/training
locations and substantive source/charging/heldout/resource guard contracts remain
separate work. A new final source/notice/manifest disposition is required before
including these files in any release.

## Internal preparation command

```bash
python3.11 -B scripts/research/prepare_delivery_prospective_fixture_locations.py \
  --closure ORIGINAL_SOURCE_CLOSURE_JSON \
  --expected-closure-sha256 INDEPENDENT_CLOSURE_SHA256 \
  --destination NEW_EXCLUSIVE_EXTERNAL_PREPARATION
```

This command executes only the source derivation utility. No fixture execution
command is offered while import/runtime/authorization gates remain open.
Five new source/AST fixture methods check an independent exact byte oracle,
unchanged function/class source spans, UTF-8/multiline offsets, unreviewed or
duplicate declarations, fabricated complete closure, corruption/gate ordering
and output exclusivity. Fabricated sources contain execution-failure sentinels;
none is executed. They do not qualify actual B numerical or original training
reproduction. Actual source-only preparation, review dispositions, prototypes
and timing are recorded in fixture_locations_preparation_20261008.json.
