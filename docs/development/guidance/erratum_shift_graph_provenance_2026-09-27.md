# Shift30 graph-provenance correction

Date: 27 September 2026. This corrects the descriptive scope of the **already frozen and completed** `protocol_pev_shift30_mean_confirmation.json`; the protocol file is preserved verbatim as the pre-submission record. Its phrases “one fixed graph template” and “fixed hierarchical topology” were read too strongly in later summaries. The five-layer **generator and layer sizes** are fixed, but the parent edges are sampled separately for each seed. `persistent_scm.py` seeds NumPy before constructing `ShiftedMechanismSCM`, and `LargeScaleSCM._build_hierarchical_graph` consumes that RNG to draw parents. `freeze_coefficients(coeff_seed)` then resets NumPy to the seed before drawing edge coefficients. Thus the recorded experiment varied DAG edges and coefficients by seed inside one hierarchical graph family; `coeff_seed` alone does not control graph construction if an SCM is instantiated outside the seeded runner.

The reproducible [audit](../../../results/research_pev_shift30_mean_confirmation/graph_provenance.csv) validates all 80 schema-v3 cells and their matched four-arm system specifications. The 20 seeds 5000–5019 have **20 distinct DAG hashes**, 35–41 edges, and 17–22 eligible intervention targets per system. Graphs and coefficients match exactly across the four arms within each seed. The original paired final-outcome analysis, sample parity, and p-values are unchanged. The statistical unit is a seed-specific graph-plus-mechanisms system, not merely a coefficient draw on one fixed adjacency.

This is within-family adjacency variation. All systems still use the same 30-node, five-layer construction, root law, function assignment rule, intervention menu, and learner. It does not test a new topology generator, hidden confounding, an independently chosen external domain, or causal graph discovery. The primary PEV-versus-coverage interval still includes zero, and PEV remains tied with naive variance. Do not describe the result as either fixed-adjacency replication or confirmed cross-family graph transfer.

The statement that both uncertainty policies “visited all 25 eligible targets” was also imprecise: 25 distinct target names appear in their **pooled** action logs, while the eligible count per system is 17–22. The action-match count of 95/640 and the final-outcome comparison do not change. Future studies should persist an explicit graph seed separate from the coefficient seed and freeze a graph-generator shift only if its scientific question warrants it.
