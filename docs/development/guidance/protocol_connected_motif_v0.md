# Connected interaction-motif simulator gate (implementation draft)

Created 26 September 2026 after the disjoint-motif screen. This is a simulator contract, **not a frozen confirmation protocol or result**. `scripts/research/connected_motif.py` builds a known DAG with k interaction children, each later motif taking the previous child and a new root as parents. Extra nodes form a linear descendant chain after the final motif, so all N nodes belong to one connected component. Every natural motif output is a noisy `a*x1 + b*x2 + c*x1*x2` mechanism. Intervening on a prior child replaces its structural equation; that child is marked ineligible as a training label for the acquired batch. The smoke check asserts the graph, dimensions, intervention values, masking, and finite outputs.

The common exact-posterior acquisition harness is now in `scripts/research/connected_acquisition.py`. Its five controls are random and balanced-coverage singles, random and balanced-coverage pairs, and posterior-risk pairs. They receive the same observed graph, batch size, update rule, and sealed feasible-action test panel. The posterior-risk selector simulates candidate contexts using the current learner coefficients in a public system object whose truth coefficients are zeroed; it never sees hidden truth or held-out labels. A pair targeted at downstream motif j may destroy an upstream training label; both selection score and actual posterior update account for that. Every selected action, acquired sample count, actuator use, masked label, cost, and final post-update motif error is logged. The evaluator is called only after the acquisition loop. This is an exact linear learner, not the neural learner used in the earlier ACE experiments.

Local development: 3 seeds (100–102), N=15 with k=1/3, root SD 0/.15, λ=0/4, fixed cost budget 400. All 24 cells have valid receipts in `results/local_connected_acquisition_dev_20260926/`. At k=3, root SD .15, λ=4, mean feasible-motif MSE was .0513 random single, .0181 coverage single, .2536 random pair, .3765 coverage pair, and .0220 risk pair. At root SD 0, λ=4, the corresponding values were 3.1446, 1.8673, .8857, 1.0509, and .3368. These three systems identify a plausible conditional design advantage but are too few for a claim. Cost and action-mask parity passed the receipt validator; all methods used the same learner, budget, and test panel.

Next CURC development grid, frozen before fresh systems: seeds 200–202; settings (N,k)=(15,3),(30,3),(100,3),(30,1),(30,10); root SD .15, λ=4, budget 400. This is 15 one-CPU jobs and five matched arms per job. Primary diagnostic is final feasible-motif MSE of risk pair versus coverage pair and coverage single; report all five arms and cost/actuator counts. This is a development scale check, not confirmatory evidence. N=300 stays gated. Extra descendant padding should not automatically degrade local motif estimation; measure full-graph error in a later phase to avoid a trivial scale claim. Freeze a distinct confirmation set only if the development contrast remains promising.

No Azure or other closed-source model calls are part of this phase.
