# Learned numerical module-library transfer screen v1

Frozen 26 September 2026 before fresh CURC targets. This is a fixed-data numerical feasibility screen for Direction C, not a neural hypernetwork or semantic-model result.

A **single** source library is learned once from 40 independent labeled source mechanisms: four feature families, ten source tasks each, 64 examples per task (2,560 source samples total). All target systems reuse the same learned prototypes. Each target has 30 local mechanisms; k in {1,3,10} are changed either to another source family or by a within-family coefficient perturbation. This contrast tests both a favorable reuse setting and a setting where retrieval can cause negative transfer. Source-family labels are hidden for target selection, though known in the synthetic generator.

Four methods receive **identical target data**: broad scratch fit, strong warm start from the old mechanism, nearest-prototype retrieval including the old mechanism as a candidate, and predictive mixture over old/source prototypes. A common four-example passive assay at each target node costs 120 samples. Remaining samples are allocated uniformly. Total target budgets are 120, 200, and 400 samples, separate from the 2,560 source pretraining samples. The compared errors are mean all-node MSE, changed-node MSE, and unchanged-node MSE on an independent fixed parent-context test set. There is no active intervention controller or full graph in this screen.

Seeds 100–111 are development data. Fresh target seeds 3000–3019 are fixed before scoring. For each seed, run all six change settings (two change types × three k values) and all four methods in one CURC CPU job. Report all settings; do not pick the favorable family-change case alone. Primary diagnostic: at 200 target samples, compare changed-node error for source retrieval versus warm start separately for family and coefficient changes. Also report target sample count at which each reaches a prespecified error threshold and account for source cost across deployment count. No claim of 2× adaptation efficiency or zero negative transfer follows unless directly measured. Learned prototypes share the test feature bank and family set, so this is deliberately favorable to retrieval; held-out function families and full-SCM interventions remain future gates.

Valid cells require 12 finite rows, system and metric SHA-256 receipts, fixed source-library hash/cost, and the exact 120/200/400 target budgets. A failed seed is rerun before any aggregate comparison.
