# PEV function-family shift pilot

Frozen 26 September 2026 before the shift-family CURC pilot. This is an **independent synthetic mechanism-family check**, not an external benchmark. `experiments/shifted_mechanism_scm.py` reuses the 30-node known hierarchical DAG and stationary coefficient draw from the prior homogeneous family, but assigns nonroot nodes one of three different forms by node index: bounded saturation, bounded two-parent interaction, or a stronger sinusoidal ripple. Root law and noise SD remain fixed. The form map is serialized for provenance and is hidden from intervention policies. This test asks whether the existing PEV advantage survives a function shift without tuning on its outcomes; it cannot establish general robustness to new graphs or real domains.

Pilot systems: seeds 42, 123, 456. Four methods: non-leaf random ensemble, non-leaf coverage ensemble, PEV integrated variance reduction, and PEV naive variance. Match the previous persistent protocol: one persistent three-member ACE-width student per system, 20 epochs per batch, 50 samples per intervention, 40 observational refresh samples every three steps, exact 2,000-sample environment budget, five PEV values, eight simulated contexts. Candidate simulations consume no environment queries. The fixed held-out feasible-intervention non-root loss after the final update is primary; broad and observational non-root losses are secondary. Report all four per-system final values, exact query ledgers, steps, runtime, system hash parity, and source revision. Do not choose a best checkpoint.

Use one CPU job per arm/system (12 jobs) on account `ucb736_asc1`, CPU partition, 4 requested CPUs, 16G, at most two hours. Because `/projects` is full, run from a pinned sparse checkout on `/scratch/alpine` with `ACE_CODE_ROOT`; store outputs at `/scratch/alpine/paco0228/ACE/results/research_pev_shift30_pilot`. Pull all results and checksum-verify them locally. This three-system pilot decides whether a fresh 20-system confirmation is justified; it is not itself a significance result. A fresh confirmation, if undertaken, must freeze seeds and primary contrasts before submission. No Azure or other closed-source model calls.

Local one-step smoke for all four methods passes receipt validation, and the serialized system hash matches across arms at seed 42. Those one-step numbers are functional checks only.

The pilot completed and is summarized in `results/research_pev_shift30_pilot/README.md`. PEV's absolute feasible-metric gain over coverage is small relative to the known observation-noise floor, while naive variance is tied. The pilot therefore does not trigger a 20-system confirmation under this metric; a sealed noise-free conditional-mechanism panel is the next evaluation repair.
