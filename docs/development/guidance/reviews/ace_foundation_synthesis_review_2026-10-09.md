# ACE foundation-model synthesis: structures worth borrowing and claims to test

Date: 2026-10-09. Scope: primary-literature and existing repository evidence review. No experiments, inference, installations or submissions were performed. The user has reopened FM+SCM research; older stop decisions below describe failed candidates, not a prohibition on new research. This document changes no delivery acceptance claim or replay gate.

**Reading key:** **Source fact** reports a paper or recorded result; **Interpretation** assesses its relevance to ACE; **Proposal** specifies work whose benefit remains untested. Public code/checkpoint availability is verified from linked author sources, not runtime compatibility or local hardware feasibility. Paper benchmark numbers are not pooled with ACE results.

## 1. Closest precedent: MDA already combines discovery, inference and design

**Source fact.** Kevin Murphy's [MDA, arXiv:2608.09696v5](https://arxiv.org/abs/2608.09696v5), revised September 27, 2026, combines LLM structure proposals, approximate Bayesian inference over structures/parameters/latent trajectories, predictive checks and VoI experiment selection. Its main design score approximates model-discrimination EIG using weighted disagreement. Appendix A.9, [“From model-discrimination to task-aware design”](https://arxiv.org/html/2608.09696v5), explicitly derives expected forecasting-risk reduction under a query distribution; this is already precedent, not an ACE novelty. The appendix also distinguishes checks made before observing a response from fitted residual backtests.

**Interpretation / borrow.** Reuse the separation between proposal generation, numerical evidence, predictive checks and design. The closest comparison is a model-pool/Bayesian-model-averaging controller with the same action menu and resource budget. Accurate interventional forecasts do not uniquely identify a mechanism.

**Feasibility.** The paper links author [NeuronBench](https://github.com/murphyk/neuronbench) and [GlucoseBench](https://github.com/murphyk/glucosebench) repositories. A reusable release of the complete MDA agent was not verified here; benchmark availability must not be described as a ready-to-run MDA implementation. No specialized pretrained MDA checkpoint was verified.

## 2. Language proposals: borrow executable hypotheses, retain numerical adjudication

**Source fact.** [LLM-SR](https://arxiv.org/abs/2404.18400) proposes equation-program skeletons, optimizes their coefficients against data and searches over candidates. Its [official code](https://github.com/deep-symbolic-mathematics/LLM-SR) provides NumPy/SciPy and Torch fitting specifications and local open-model or API sampling. It is equation discovery from supplied data, not evidence of adaptive intervention efficiency or SCM identification.

**Proposal.** Translate proposals into a restricted mechanism representation: declared parents, units/domain, supported operators, coefficient constraints and noise assumptions. Fit coefficients numerically using eligible rows. Give a data-only symbolic/family selector the same grammar; otherwise semantic knowledge and model-class privilege are confounded. Cache raw proposals and charge retries, rejected outputs and coefficient search. Adapting the local-model backend requires verification; the repository's example backbone is not a small-model resource estimate.

**Source fact.** [Automated Statistical Model Discovery / Box's Loop](https://proceedings.mlr.press/v235/li24v.html) alternates language-generated probabilistic programs with numerical inference and model criticism. **Borrow:** likelihood/noise specifications and residual critiques, especially when deterministic equation fitting would confuse noise with misspecification. It does not certify causal interpretation of a generated program. BoxingGym supplies a concrete integration path below; an independent reusable Box's Loop release was not verified in this review.

## 3. BoxingGym: usable experiment/goal interfaces, limited causal interpretation

**Source fact.** [BoxingGym](https://arxiv.org/abs/2501.01540) separates experimental design and model discovery in simulated domains. Its [author repository](https://github.com/kanishkg/boxing-gym) exposes environment experiment calls, goal-specific prediction evaluation, optional descriptive priors and probabilistic-model integration. EIG and prediction error are distinct metrics. The documented EIG-regret comparator searches sampled candidate queries; it is not a certified global optimum.

**Proposal.** Borrow `run_experiment`/goal separation and public/private evaluation boundaries. Adapt each domain's controls, costs and observation contract explicitly: a queryable regression environment does not automatically expose independent SCM interventions or natural labels for every node. Use private simulator truth for scoring only. Familiar published equations and informative descriptions are contamination risks, so include renamed variables, incomplete independently authored metadata and genuinely held-out forms. The benchmark is code/data, not a pretrained scientist checkpoint; LLM and numerical inference costs are additional.

## 4. Numerical PFNs: prediction and causal-effect estimation are different interfaces

**Source fact.** [TabPFN-v2](https://www.nature.com/articles/s41586-024-08328-6) learns tabular prediction from synthetic task priors and uses in-context training examples for new datasets; the paper studies up to 10,000 samples and 500 features. [Official code](https://github.com/PriorLabs/TabPFN) and [v2 regression weights](https://huggingface.co/Prior-Labs/TabPFN-v2-reg) are available. Current package defaults point to later releases: explicitly select v2 and pin package/checkpoint revisions. Code and weights have separate licenses; the v2 weights use the Prior Labs license with attribution requirements.

**Interpretation / proposal.** A strong candidate is one regression context per mechanism: measured parents as inputs, natural child labels as outcomes, with clamped rows excluded. This is conditional prediction; synthetic SCM pretraining does not grant causal identification. Test adaptive-design/support shift and composed rollouts. Predictive intervals alone do not provide coherent posterior function draws or distinguish epistemic uncertainty from observation noise; a VoI adapter needs these semantics validated. CPU/GPU latency and memory were not measured here.

**Source fact.** [CausalPFN](https://arxiv.org/html/2506.07918v2) instead amortizes observational causal-effect estimation under strong ignorability: unconfoundedness and positivity. The published implementation focuses on binary treatment. [Author code](https://github.com/vdblm/CausalPFN) supplies `fit(X,T,Y)`, CATE and ATE estimators; [released weights](https://huggingface.co/vdblm/causalpfn/tree/main) include `causalpfn_v0.pt`.

**Interpretation.** It is a useful effect-estimation comparator on compatible tasks, not a drop-in multivariate continuous-intervention mechanism learner. Hidden confounding, inadequate overlap or adaptive non-iid collection do not inherit the paper's identification/consistency results. In-context updating is not weight fine-tuning, and neither model supplies an ACE acquisition policy by itself.

## 5. Design policies: fast decisions have an upstream training cost

**Source fact.** [DAD](https://proceedings.mlr.press/v139/foster21a.html) trains a history-to-design policy with contrastive information objectives under a specified generative model, amortizing sequential design computation. [Official code](https://github.com/ae-foster/dad) is available. **Borrow:** history encoding, matched static/random policies, and separate offline-training/live-decision accounting. These are model/task-specific design networks, not general pretrained mechanism estimators.

**Source fact.** [Step-DAD](https://proceedings.mlr.press/v267/hedman25a.html) periodically infers a posterior and refines the policy for the remaining experimental horizon. Its [author code](https://github.com/marcelhedman/stepdad) implements importance sampling and policy training/refinement. **Borrow:** an explicit inference/refinement schedule and computation-budget ablation. Reported prior-perturbation robustness does not guarantee recovery from an absent mechanism family. Training and test-time refinement must both be charged; transferable ready-made checkpoints were not verified.

**Source fact.** [iDAD](https://arxiv.org/abs/2111.02329), with [official code](https://github.com/desi-ivanova/idad), extends amortized design to implicit models without likelihood evaluation. **Boundary:** a simulator/training distribution remains necessary; removing an analytic likelihood does not remove misspecification or data-generation costs. **Proposal:** initially enumerate a small validated menu before adding amortized policy training, so inference quality and design quality can be diagnosed independently.

## 6. Additional close work constrains the novelty claim

- **Interventional PFNs:** [Do-PFN](https://arxiv.org/abs/2506.06039) trains on synthetic observational/interventional pairs to predict conditional interventional distributions; [author code and pretrained models](https://github.com/jr2021/Do-PFN) are public. The documented interface uses binary treatment and continuous covariates/outcomes. Borrow an explicit interventional predictive target. **Interpretation:** averaging over a prior of possible SCMs does not uniquely identify effects when observationally indistinguishable SCMs disagree; test prior sensitivity rather than treating a confident forecast as identification.
- **Causal-prior construction:** [CausalFM](https://arxiv.org/abs/2506.10914) formulates validity criteria for causal priors and trains a back-door CATE model. Its [toolkit](https://github.com/yccm/CausalFM-toolkit) includes back-door, front-door and IV model/data pipelines. Borrow assumption-specific adapters; a framework supporting several identification settings does not establish that an arbitrary ACE task satisfies one. Code availability was verified; an immediately usable pretrained checkpoint was not verified here.
- **Decision-aware amortization:** [Huang et al., NeurIPS 2024](https://arxiv.org/html/2411.02064v2) define expected decision utility gain and a transformer neural decision process with prediction/design heads; [code](https://github.com/huangdaolang/amortized-decision-aware-bed) is public. Borrow the distinction between informative parameters and useful terminal decisions. Target-aware sequential design is already established; distribution-trained policies still need transfer tests. A general reusable checkpoint was not verified.
- **Prediction-oriented information:** [Kurniawan et al., v5](https://arxiv.org/html/2411.02740v5), with [code](https://github.com/yonatank93/information-matching), match Fisher information to downstream quantities of interest. Borrow a sensitivity/information baseline on a specified differentiable model. Local information approximations are not exact nonlinear posterior-risk reductions or causal identification proofs.
- **Optimization:** [LLAMBO](https://arxiv.org/abs/2402.03921), with [code](https://github.com/tennisonliu/LLAMBO), uses language for warm starts, candidate sampling and surrogate modeling. Borrow component ablations. Its black-box optimization objective seeks good objective values; finding a maximizer differs from learning forecasts across a declared deployment distribution. The original API backend is not a verified currently runnable endpoint.
- **Memorization control:** [LLM-SRBench](https://arxiv.org/abs/2504.10415), with [code/data](https://github.com/deep-symbolic-mathematics/llm-srbench), uses transformed and synthetic equation tasks to probe discovery beyond common-form recall. Borrow these stress-test principles; a public benchmark is not proof of pretraining exclusion for every candidate model.

## 7. Independent mechanisms: autonomy is an assumption to test

**Source fact.** [Learning Independent Causal Mechanisms](https://proceedings.mlr.press/v80/parascandolo18a.html) learns competing inverse experts on transformed image distributions. [Toward Causal Representation Learning](https://arxiv.org/abs/2102.11107) explains autonomous causal modules and the assumptions needed for representation/transfer. **Interpretation:** causal autonomy neither makes node observations statistically independent nor guarantees independently factorized parameter posteriors. A known graph narrows this project's question to mechanism learning and intervention forecasting; it does not establish graph discovery or unrestricted identification.

**Source fact.** [Can LLMs Learn Independent Causal Mechanisms?](https://aclanthology.org/2024.emnlp-main.381/) studies sparse modular language models and reasoning generalization; [code](https://github.com/Strong-AI-Lab/modular-lm) is public. **Boundary:** language-domain modules are not thereby identified physical SCM mechanisms. **Proposal:** test local mechanism changes, unchanged-module protection and composed-output consequences before claiming modular causal transfer. Ready-made physical mechanism checkpoints were not verified for these works.

## 8. Repository counterevidence that the new protocol must retain

- **Semantic value was not isolated:** the [Lotka numerical selector](../../../../results/local_boxing_lotka_selector_dev_20260927/README.md) found the same family as the [open-language proposer](../../../../results/research_boxing_lotka_open_proposal_dev_v1/README.md). The [source-count gate](../../../../results/research_boxing_signal_prior_gate_dev_v1/README.md) accepted both correct and false counts in all three reused development worlds; false counts could even predict better. Predictive adequacy and true mechanistic structure must have separate outcomes.
- **Transfer harmed protected components:** [retrieval](../../../../results/research_learned_transfer_v1/README.md) helped family changes but harmed coefficient changes and unchanged nodes. The [held-out-form gate](../../../../results/local_transfer_heldout_form_fresh_20260929/README.md) failed unchanged-node protection at low source budget (point ratio 1.1551; paired difference interval crossed zero). Its changed-node gain matched adaptive scratch. This is a failed full gate, not proof of population harm or an FM benefit.
- **Abstention has a usefulness cost:** [prequential switching](../../../../results/local_transfer_prequential_dev_20260926/README.md) avoided false switches in tested settings but adapted too slowly at low budget. [Threshold scans](../../../../results/local_prior_gate_threshold_audit_20260926/README.md) found no rule dominating correct/wrong-prior conditions; post hoc thresholds cannot become fresh confirmation results.
- **Action validity was only engineering evidence:** the [eight language fixtures](../../../../results/local_action_language_fixture_20260930/README.md) were solved by a developed rule baseline. The [validator smoke](../../../../results/local_action_menu_validator_smoke_20260929/README.md) established rejection of invalid actions, not semantic generalization, proxy identification or better acquisition.

## 9. Proposed ACE synthesis and its decisive falsifiers

**Interface proposal.** Start with a known, fully observed DAG and invariant mechanisms under validated interventions. Keep five separate contracts:

1. A proposer returns typed candidate mechanisms/priors, provenance and supported domains; it cannot query the environment or see private outcomes. Language confidence is not a likelihood or calibrated prior weight.
2. An observation router records measured parents, natural child labels and clamp/retention masks. Updates use only acquired eligible rows. Learning a proxy's effect requires a separately justified intervention/measurement model.
3. A numerical learner exposes predictions and explicitly specified joint uncertainty/noise semantics. Maintain a strong broad data-only fallback; preserve original contexts and all candidate decisions.
4. A scorer evaluates expected target-risk reduction under a frozen deployment distribution and the full action-induced predictive distribution, including random parent features and joint eligible labels. Score a paid action by this reduction divided by its declared positive cost; track measurement, inference, fitting and source-training costs separately. Nonlinear plug-in features or PFN uncertainty used without a coherent update model are surrogates and must be labeled as such.
5. An independent evaluator scores pre-update forecasts, composed held-out forecasts and local diagnostics. Ideal Bayesian VoI and reduction achievable by the actual finite-budget learning algorithm are distinct quantities. Log predicted utility before the action and assess it afterward; shared errors can produce confident, useless scores.

**Three decisive tests, to be frozen after development:**

1. **Model contribution:** identical acquired histories, fixed fitting resources and matched grammar; compare data-only, numerical PFN, language-proposed, and combined variants. Use independently authored informative/anonymous/misleading metadata, disjoint source/target families and absent-form cases. Failure to improve over the strongest matched data-only method falsifies the claimed FM predictive contribution, even if proposals parse correctly.
2. **Acquisition contribution:** cross estimator choice with random, systematic/endpoint or factorial coverage, variance and target-risk policies on matched menus; include strong evidence-aware schedules where applicable. Fix update/final-fit rules and account for all costs. If gains disappear when the estimator is held fixed, claim improved estimation rather than improved acquisition. A scoring change alone does not establish calibrated VoI or global optimality.
3. **Recovery and delivery:** null changes, coefficient shifts, family changes and missing-family mechanisms; predeclare tolerable harm, recovery budget and unchanged-mechanism protection alongside target loss. Record false acceptance, false abstention and time to useful recovery. Final-fit objectives get a separate matched-history/budget comparison and independent validation. Average target improvement cannot rescue a failed prespecified protection gate; permanent fallback cannot demonstrate useful prior adaptation.

**Interpretation of possible novelty.** A defensible candidate is a measured advantage from a specific eligibility-aware modular FM interface, uncertainty/update model and prior-recovery strategy under charged experimental and computational budgets. Generic LLM+Bayesian+VoI integration, causal modularity and task-aware design are precedented. An integration diagram, one selected trace, or a favorable reused generator establishes none of novelty, causal identification or method superiority. The deck's predetermined first trace can explain the pipeline; evidential claims require all frozen worlds and all failures.

The next useful order is component evidence first, then a crossed closed-loop pilot on fresh worlds, then separately frozen confirmation. Public implementation availability supports trying components; it does not establish compatibility, calibrated uncertainty or external usefulness. All tests above are proposed, not results produced by this review.
