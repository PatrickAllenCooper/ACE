## Findings and dispositions

1. **Acceptance checks were too weak.** Totals alone omitted A's full
   seal/configuration audit and C's exact condition/artifact sets.
   **Fixed:** the planner rechecks the independent A auditor, binds its full
   receipt-set digest to the accepted immutable gate, checks C's accepted receipt
   digests and requires exact condition/artifact membership. A changed accepted
   receipt set fails a regression test. Original gates and receipts are unchanged.
2. **Composite reconciliation was not connected to the planner.** The A/C
   candidate contains single-source originals and no B snapshot integration.
   **Preparation advanced, final integration open:** a separate read-only inventory
   reconciles all 560 B model/receipt pairs and input bindings across the canonical
   two snapshots, retaining missing indices 560–639. Conflicting duplicates fail.
   Final B release planning must consume complete inventory source lists after
   acceptance; this A/C plan must not be represented as a full B release.
3. **Anonymity-screen bypasses.** Escaped JSON paths defeated raw matching; an
   arbitrary script could claim the verifier exemption; C used an exclusion list.
   **Fixed:** structured metadata is decoded, the exemption requires executing
   trusted verifier bytes, and C has an explicit field allowlist. Escape and
   exemption regressions pass. This remains a limited identifier screen.
4. **Scientific replay code was absent.** Learner modules alone omitted original
   workers/guard and a relocated scientific entry point. **Partly advanced:** a
   separately hashed C adapter now replays retained neural checkpoints and linear
   predictions, NMSE and conditional bootstrap intervals from a relocated bundle.
   Actual prediction discrepancy is zero. A/B replay, original-worker provenance,
   confirmation statistics/accounting and final bundle completeness remain open.
   The integrity verifier is not advertised as refitting or scientific replay.
5. **Builder self-check was mislabeled independent pinning.** A freshly computed
   digest cannot establish independent origin. **Fixed:** reports now distinguish
   `expected_digest_supplied` from `pin_origin_verified: false`. Pin origin requires
   independent custody/human review. Original-versus-derived bindings are tested.
