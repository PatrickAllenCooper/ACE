The proposed profile is 2CPU, 7680MiB, 3600 seconds, zero GPUs, acpu/cpu-normal/ucb736_asc2, no requeue. Every deadline uses the original parent monotonic origin. Preparation must finish before origin+1200, including parent full authentication, runtime staging and the worker's repeated full authentication. The worker publishes `worker/authentication-complete.json` only after that authentication completes. Reporting startup must complete before both authentication-complete+120 and origin+1320.
