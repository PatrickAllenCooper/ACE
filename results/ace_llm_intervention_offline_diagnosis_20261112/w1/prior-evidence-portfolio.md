## (c) Theoretical ideas and the LLM roles they could support

Ideas recorded in `G/ace_theoretical_ideation_2026-10-08.md`:

1. Organising principle: reduce error in the deployed model under the intended actions. Eligible observations differ from responses (a clamped node gives no natural label).
2. Data-processing bound: refitting extracts but does not create information. Empirical-risk comparison bound delta + 2 epsilon. Predicts that an equal-compute pooled comparator removes much of the delivery advantage. Evidence: all-paid vs admitted-long ratio 0.980 against short-fit ratios 0.096 and 0.034 (exploratory).
3. Exact signed DAG error propagation e = (I - H)^-1 r; spectral radius of a DAG Jacobian is zero so path sums matter. Off-manifold non-identifiability under root-only interventions. Proposed mechanism + terminal + propagation-regularised objective. Not tested.
4. Rank-one ensemble makes integrated variance reduction rank identically to plain variance. A candidate explanation for the PEV / naive-variance tie; never checked on saved snapshots (the two policies chose the same target in only 95 of 640 paired steps).
5. Target-relevant posterior risk per cost: gain (g' Sigma x)^2 / (sigma^2 + x' Sigma x). Evidence for: the November target-risk planner, which scores expected reduction in target-prediction uncertainty per cost unit (`G/ace_llm_intervention_target_risk_2026-11-02.md`), was the best of eight policies (11.625). **[inference]** that planner is the same idea in implemented form; the documents do not state the lineage explicitly.
6. Endpoint values give three times the information of uniform values in a scalar model. Evidence mixed: endpoint coverage won on 3 dev systems and lost on 20 fresh.
7. Resource allocation over measure, fit or stop with separate prices. Not tested.

## (e) TabPFN / foundation-predictor cycle (9 October)

Setting: known chain X -> M -> Y, fixed shared histories of 32 paid responses, six base systems per screen, zero GPU, 90.04 measured child CPU seconds in total. Ratios are geometric means of within-system composed-Y NMSE ratios.

- Component screen, 30 cells, grammar contains the truth (`G/ace_foundation_component_results_2026-10-09.md`; verified against `R/ace_foundation_component_20261009/ace-foundation-component-pilot-20261009-01/descriptive_summary.json`): polynomial ridge 1.8290 (worse 5/6), ExtraTrees 12.957 (worse 6/6), TabPFN-v2 2.6432 (worse 5/6; M-local 1.4505, Y-local 6.3890), language 1.0000 purely by fallback.

Harm: PFN24 worsens the unchanged Y mechanism in 6/6 systems in three strata.

All four selector ablations gave identical forecasts in missing-Y.
- Conclusions recorded: keep a compact numerical SCM as reference; flexibility explains much of the gain attributed to pretraining; selection reliability must precede any acquisition study; fixed-history prediction says nothing about intervention savings.
- Prepared but unexecuted: a 312-cell validation-budget protocol with reserved seeds 94000-94005, and a fixed scalar mechanism adapter (`G/ace_foundation_fixed_mechanisms_2026-10-09.md`), neither qualified with real teachers.

Why the six language proposals failed the output contract (verified in `.../9100{0..5}/prompt.txt`, `raw_response.txt`, `language.json`):

- Contract: one strict JSON object with exactly keys M and Y, each value one of `linear`, `quadratic`, `tanh`; no surrounding text; no retries; invalid output falls back to the numerical grammar selector.
- Model and interface: Qwen3-0.6B (revision `c1899de2...`), greedy CPU generation, thinking disabled, at most 64 new tokens, unconstrained decoding, one request per world, anonymised names, only the first 8 parent-child pairs per mechanism.
- Raw outputs: all six begin with a Markdown fence, so `parse_error` is "Expecting value: line 1 column 1 (char 0)". Three return `"Y": "Y"` (91000, 91001, 91005), two return a numeric string for Y (`"-0.482133"`, `"-0.952318"`), one (91004) echoes the data array and is cut at 64 tokens. Five say `"M": "linear"` regardless of the true M family.
- The results note states that removing fences would not rescue the result. **[inference]** The failure combines a format defect (no grammar constraint) with a content defect (a 0.6B model given raw number pairs and no semantics has no basis to choose a family). The November policy work fixed the first with token-level grammar constraints (`G/ace_llm_intervention_grammar_2026-11-02.md`) but used the same 0.6B model.
