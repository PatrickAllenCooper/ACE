## MISSING_FROM_ALL
- A single shared in-process bench, budgeted and accepted once as its own component, built by promoting scratch code that already reproduces the saved artifacts. Every proposal depends on it, but none costs it once with an
  acceptance test.
- A proportionate two-tier custody and review regime fixed before work starts: development-light (committed protocol, hash manifests, append-only outputs, failure ledger, review at gates only) and confirmation-full. It should
  include a cap of about 3,000 lines on new non-test harness code before Gate B, and a rule that every new guard ships with a fixture built from saved artifacts.
- A measured MPS and LoRA throughput and fidelity pilot as the first approved execution, and a plain statement that training runs over about 45 minutes cannot use the 1-hour gpu-testing slice without a qualified resume.
- Conditional pre-approval of compute tranches tied to gates, so each gate does not wait on a new human decision. One storage decision alone cost 23.5 hours last cycle.
- Named, scheduled human authors for held-out prose, and a parser author who does not develop the LLM, each with an effort budget. Both are on the critical path of every text-channel class.
- A leakage guard for in-process execution: policy code receives only the public envelope and cannot import the evaluator or the private world. Process isolation used to provide this.
- A dated ICML go/no-go with writing in parallel, and a statement of the minimum paper that exists at each gate.
- Promotion of existing exports instead of recomputing them: decisions_verifier.csv, with 16,384-draw reference scores for all 8 actions at all 4,371 decisions, and the training-label check.
