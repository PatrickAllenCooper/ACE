GPU builder keeps all original metadata arguments, --cpu-remote-custody (selected terminal/remote), adds --cpu-terminal-mirror (second whole selected capsule), --storage-config and --storage-config-sha256. Finalizer keeps both original GPU capsule path arguments and adds --storage-config/--storage-config-sha256. Both collectors replace old stream-helper CLI arguments with --backup-root (new exclusive projects location). Original collector own-source/Git/review, packet/job/intent, current and predecessor acceptance pins remain required.

Storage config schema `ace-compact-downstream-inputs-v1`, predecessor `cpu` for GPU or `gpu` for finalizer. Exact `members` keys: authority, authority_review, backend, backend_review, receipt, seal, after, reference. Each entry has independent path and sha256. backend also has full source_commit and repository_path; backend_review has repository_path at that same commit. Config <=128KiB; complete selected capsule seal <=128MiB; each other storage metadata <=32MiB. Config is outer metadata only.

Member sources: authority = adopted operational storage amendment; authority_review = its independent review; backend = captured reviewed helper; backend_review = its independent review; receipt = original predecessor remote-custody.json; seal = original predecessor custody-inventory.json; after = original predecessor inventory_after_transport.json; reference = original predecessor predecessor-reference.json. Receipt.local_root is never rewritten.
