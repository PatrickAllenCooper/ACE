# Numerical mechanism-family selection on the BoxingGym development worlds

This local, post hoc diagnostic gives a public-data numerical selector the same coupled-bilinear and independent-exponential structural choices offered to Qwen, plus the RBF and Fourier fallback families. It uses only eight acquired time-response pairs per world. Each candidate is assessed by leave-one-out error on the public observations; the winner is refitted to all eight. A separate scoring process reads the sixteen private held-out responses. The coupled fit estimates **both initial states and all four rates**; no true initial state or hidden parameter is supplied. Fixed generic multistarts are used.

The numerical selector chose `coupled_bilinear_ode` in all three reused development worlds. Held-out MAE was 0.348 (seed 42), 0.302 (123), and 0.418 (456), across both observed populations. This is near the deliberately privileged equation-form ceiling and far below the flexible time-only fits on seeds 42 and 123. It is a strong **negative control for a unique foundation-model contribution on this candidate menu**: the correct family is already recoverable from eight observations when the menu contains it. A Qwen canary can still test offline inference, prompt differences, and typed-output validity, but selecting the same family would not show that semantic knowledge helped. Do not expand this familiar two-variable benchmark into a large seed study on that basis.

Three selection files, fitted models, score files, and SHA-256 receipts are under `seed_*`. All three have exactly eight training and sixteen held-out responses and finite scores; selectors read zero private files and made zero model calls. This is reused development evidence, not a fresh confirmatory result. No CURC job or model API call was used.
