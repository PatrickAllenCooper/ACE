# Bounded-degree joint-intervention confirmation

The [protocol](../../docs/development/guidance/protocol_connected_binary_tree_pair_confirmation_2026-09-28.json) was committed at `2ab453fe103a4313a6b29ed112958362d229014d` before generating fresh systems 500–519. That revision also supplied the unchanged simulator, exact-posterior learner, action menu, and sealed evaluator. All 20 systems ran locally in a few seconds, so a CURC allocation was unnecessary. No new closed-model call or environment outside this numerical simulator was used. The shared CURC SSH channel was healthy and no `acer_` jobs were queued or running at the check.

The final feasible-motif MSE (lower is better), averaged over 20 paired systems, was: random single 0.08954, coverage single 0.05260, random pair 0.19243, coverage pair 0.03706, posterior-risk pair 0.02336, balanced-risk pair 0.02879, hub-coverage pair 0.03904, and hub-random pair 0.04151. [Every system and arm](summary.csv), plus actions, exact costs, system definition, and SHA-256 receipts, are retained here.

**Prespecified primary contrast:** coverage pair minus coverage single has mean −0.01554 and two-sided 95% paired-t interval **[−0.03150, +0.00043]**; the ratio of mean errors is 0.705 and coverage pair wins 14/20 systems. The protocol required both a ratio below 0.90 and an interval upper endpoint below zero. The ratio condition passes, but the interval condition fails. Thus the joint-action advantage is *not confirmed* by the frozen gate.

**Prespecified within-pair contrast:** coverage pair minus random pair has mean −0.15537 and 95% paired-t interval [−0.25980, −0.05094]; coverage pair wins 18/20. The within-pair coverage-selection gate passes in this particular generator. The random-pair arm is very poor here, so this comparison alone does not establish a general controller advantage.

Posterior-risk pair has the lowest mean error in these fresh systems, reversing the three-system development result where coverage pair won all three. That reversal is exploratory because the frozen confirmation question and gate concerned coverage pair versus single and random-pair controls. Do not promote posterior-risk from this post hoc observation or chase new seeds selected for its result. The result remains limited to one synthetic bounded-degree graph family with 40 samples in pair arms versus 80 in single arms at matched total cost. There is no foundation-model result.

Validation covered all 20 source revisions and topology/settings, 160 finite method rows, 1,000 logged action decisions, per-cell file hashes, exact sample and actuator costs, and the suite hash. An initial generated copy carried a mistyped revision string; it was moved out of the repository before any outcome inspection and the full suite was regenerated with `git rev-parse HEAD`. Only the correctly attributed copy is archived here.
