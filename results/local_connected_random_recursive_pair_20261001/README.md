# Fresh random-recursive joint-intervention gate

Frozen protocol: `docs/development/guidance/protocol_connected_random_recursive_pair_2026-10-01.json`. Source revision: `90aae16a`. Execution was local CPU only on 1 October 2026; no CURC job, GPU, or model API call. This is a new synthetic graph family: each motif after the first selects an earlier child as its first parent with an independent seeded graph RNG. All 40 systems have distinct realized parent structures. The graph RNG leaves the existing coefficient RNG unchanged.

The frozen primary endpoint is final noise-free feasible-motif MSE. Risk-pair mean was **0.0227035**, versus **0.0591759** for the fixed factorial-hub pair policy. Their ratio of means is **0.38366**; the paired mean difference is **−0.0364724**, with two-sided 95% paired-t interval **[−0.0548996, −0.0180453]**. Risk-pair won on 31/40 systems and passes the prespecified ratio-below-0.80 plus upper-interval-below-zero gate. Both primary arms spent exactly 360 cost units per system. Single-action arms spent 400 under the same cap because their discrete batch cost differs; they are descriptive controls rather than the primary matched-cost comparison.

The other arm means and all per-system results are in `analysis.json` and `summary.csv`. The suite has 360 arm cells and 17,600 acquired arm-response counts. Sealed evaluation panels and policy-internal simulated contexts are excluded from that acquired count. The run recorded 10,792 masked child labels. Each of 40 cell receipts hashes its metrics, actions, and system specification; the suite receipt hashes protocol, summary, and analysis. Independent checks reproduced the hashes, seed/protocol agreement, costs, finite errors, and all response counts. A full second run was byte-identical (`diff -qr` returned no differences).

Interpretation: this supports an adaptive **numerical** pair-selection advantage on one more synthetic topology. The earlier binary-tree gate passed, while the fanout gate failed. These sequentially chosen graph families do not establish a general topology effect or a foundation-model contribution. A real-domain test or prospectively chosen graph distribution with a strong matched fixed schedule is still needed before broad claims.
