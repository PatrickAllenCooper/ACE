# Connected transfer query-accounting gate

At pinned revision `463bf3d9`, three new N=30, ten-motif connected fanout systems (1700–1702) tested the target acquisition contract. This is an accounting smoke test, not an estimator comparison. Each target system has three coefficient changes. A campaign collects four fully observed observational trajectories, then five batches of eight pair-intervention trajectories using a fixed varied-value schedule. One trajectory costs one unit, with four more units per actuated node.

Per system: 44 target trajectories, 80 actuator uses, 364 total cost units, 432 natural motif labels, and eight masked motif labels. Across three systems: 132 trajectories, 240 actuator uses, cost 1,092, 1,296 natural labels, 24 masked. Every trajectory observes all 30 node values, but only natural mechanism outputs are eligible for fitting; intervention on motif 1's first parent masks motif 0's conditional label for eight trajectories. The observational assay's 40 natural motif labels are shared with every future policy arm and are included in these totals. Simulator-generated and acquired trajectories coincide in this gate; no source data or evaluation samples are counted here.

Graph, source/target coefficients, actions, acquired node values, motif features, and natural masks are archived per system. All cell receipts and suite hashes, array shapes, exact costs, and deterministic byte-identical replay validated. No CURC job or closed-model API was used. The former independent-node floor-six *per-node* response budget does not apply to fully observed connected trajectories. Next run must use this cost definition for every pair-policy arm and report any policy-dependent masking.
