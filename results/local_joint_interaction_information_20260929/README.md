# Interaction information with nuisance main effects

For the known-form model `y = beta0 + beta1*x1 + beta2*x2 + beta12*x1*x2 + Gaussian noise`, information about `beta12` must be computed **after projecting the interaction regressor onto the intercept and both main-effect regressors**. If all experiments set `x1=1` while `x2` varies naturally, `x1*x2=x2`; the interaction is exactly confounded with `beta2`, even when background variation is nonzero. A single joint pair `(1,1)` is likewise uninformative about the interaction when the other coefficients are unknown. Repeating one action does not resolve rank deficiency.

Two different single-target values (`x1=−1,+1`) with natural `x2 ~ N(0,tau²)` give population nuisance-adjusted information `tau²/sigma²` per response. Passive independent `x1,x2 ~ N(0,tau²)` gives `tau⁴/sigma²`. A balanced joint factorial design over `(±1,±1)` gives `1/sigma²`. At `sigma=0.15` and `tau=0.1`, those are 0.444, 0.00444, and 44.444 respectively. With deterministic background `tau=0`, the varying-single designs provide zero interaction information while the factorial joint design remains full rank. This is a property of the specified action menus and nuisance coefficients, not a universal benefit of using two actuators.

The [numerical audit](information.csv) constructs 400 rows per design at `tau` in {0, 0.01, 0.1, 0.5}, reports full-design rank, and computes the interaction-column residual information. Fixed single and fixed joint designs have zero nuisance-adjusted information in all 20 cases where applicable; the balanced factorial has rank four and exact information 44.444. Finite Gaussian draws for the other designs approach their population values. A deterministic replay matched the output byte-for-byte. This uses linear algebra only: zero simulator oracle queries, no CURC job, and no model API call.

Implication for B1/B2: define the allowed action **values and sequence**, background distribution, nuisance knowledge, and cost before asserting that a joint action supplies new identification. Compare a varied single-target design with a varied joint design; a fixed single value is an insufficient control. The paper should distinguish exact nonidentifiability at zero variation or a rank-deficient menu from low but nonzero finite-budget information.
