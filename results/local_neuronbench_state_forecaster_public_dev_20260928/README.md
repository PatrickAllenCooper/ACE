# Public-only NeuronBench state-model development gate

The [protocol](../../docs/development/guidance/protocol_neuronbench_state_forecaster_public_gate_2026-09-28.json) and implementation were committed at `839e344d4141c6e9259d7a226598c13af4a482d4` before the full twelve-cell screen. A one-cell `h_sag` canary exposed numerical warnings, which were repaired before this freeze; its public error was already known. The model is a world-agnostic forced integrate-and-fire approximation with adaptation and hyperpolarization recovery. It fits subthreshold voltage derivatives on three of four public traces, chooses a spike threshold from those three public counts, and predicts the fourth. Four folds per cell give **48 public leave-one-protocol-out forecasts**. Mean, nearest-waveform, and fixed-penalty ridge controls use exactly the same public folds. No private forecast response, upstream world-specific truth, new environment action, or model API was used.

Across all 48 folds, mean absolute spike-count error is **7.00** for the state model, 8.56 for the mean control, 9.50 for nearest, and 8.11 for ridge. However, the state model is better than the *best* control in only **5 of 12** world-and-acquisition cells, short of the frozen gate of eight. It helps on some public cells, especially `z_rebound` random and `na_fatigue`, but has large failures on `h_sag`, `ca_rebound`, and `d_type`. See [all cell errors](summary.csv) and the four public folds in each cell JSON.

The protocol required both a lower pooled MAE than all three controls **and** at least eight cell wins. Only the first condition passes. **Stop this state-model variant before private forecast scoring.** This negative development outcome does not show that full traces are useless or that a better dynamics model cannot work. It does show that this cheap three-state approximation is not reliable enough to support an acquisition claim here. The designed worlds and acquisition data were already used in prior development; no independent generalization claim follows.

All 12 public problem/observation hashes, 48 trace hashes, 48 finite model/control forecasts, fixed timing and exact four-observation folds, and the suite receipt validate. The run took seconds locally; no CURC allocation was needed. The shared CURC connection was healthy and no ACE `acer_` jobs were active at the check. Other projects and closed-source APIs were untouched.
