# Hard versus soft prior-gate development audit

This is a **post hoc** audit of the existing 12 numerical-prior development systems (seeds 100–111), not a new independent experiment. The script verifies the archived metric-file SHA-256 for every seed and reads the two proposal conditions at budgets 16/32/64. It compares the original soft validation gate with hard selection of the proposal when its eight-example held-out SSE beats the broad fallback by a specified margin. All eight validation examples remain inside the acquired-data budget. The four exploratory SSE thresholds, −0.045, 0, 0.045, and 0.09, and all 24 condition/budget/threshold summaries are in `summary.csv`; its receipt and unique-grid checks pass.

At budget 16, the most conservative threshold (−0.045) gives wrong-proposal mean MSE **0.01468**, versus **0.01493** for the original soft gate and **0.01971** for broad alone, but raises correct-proposal error to **0.01234**, versus **0.01107** for the soft gate. At budget 32, the same threshold avoids wrong proposals (hard and broad both **0.00532**) yet gives correct-proposal MSE **0.00471**, versus **0.00431** for the soft gate. Less conservative thresholds recover more correct-prior value while admitting more wrong-prior harm. At budget 64 the eight-example validation scores nearly converge, so fixed hard thresholds become especially brittle.

No tested hard threshold dominates the original soft rule across correct and wrong conditions and budgets. These rules were inspected on development data after the v1 fresh result; none may be retroactively scored as a prespecified confirmation method on seeds 2000–2019. The benchmark also gives the correct form nearly explicitly through its typed proposal, so this audit says nothing about whether a foundation model can generate useful forms. The next useful test would change the proposal reliability problem itself, with independently authored incomplete metadata and deliberate misspecification, before using CURC for a new confirmation. No closed-source model API was used.

Reproduce with `python3 scripts/research/audit_prior_gate_thresholds.py --output results/local_prior_gate_threshold_audit_20260926`.
