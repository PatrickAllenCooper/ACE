# Held-out-form transfer gate (29 September 2026)

The [protocol](../../docs/development/guidance/protocol_transfer_heldout_form_fresh_2026-09-29.json) and runner were committed at `6c96c5c102d5ffb0488c1cba9076edc6511a86f7` before generating 20 new systems (1200–1219). Each old/source module was estimated from 16 or 64 separately counted source responses per node. One target node changed. In the primary `heldout_tanh` setting, its conditional mean adds `0.85*tanh(1.7*x1 + 0.8*x2)`, a form absent from the six-feature fitted bank. The matched-family setting is a positive control. All methods use the same acquired target prefixes, with 200 target responses per policy.

**The full held-out-form gate fails.** At 16 source responses per node, the adaptive top-eight soft mixture's changed-node MSE is 0.29645 versus 0.93386 for uniform soft mixture (ratio 0.3174), and it is effectively equal to adaptive scratch. But its unchanged-node MSE is 0.011581 versus 0.010026 for uniform soft mixture: ratio **1.1551**, exceeding the frozen 1.05 protection limit. The 20-system paired difference interval is [−0.000044, +0.003155], so this point-gate failure is not a statistically resolved population harm claim. At 64 source responses per node, the unchanged ratio is 1.0040 and all four point contrasts pass. The protocol required both source-size strata.

The changed node was in the top eight for all 20 systems in each setting. Adaptive scratch has the same changed-node MSE as the soft mixture to printed precision. For the held-out form, the six-feature bank's noise-free projection residual averages 0.04549 across the independent test designs, while the candidate's changed-node MSE is 0.29645. This is a substantial model-class limitation. The source-warm fit at source size 16 has lower changed-node MSE (0.24444) than the adaptive soft mixture (0.29645), so the mixture's scratch-favoring evidence is not uniformly helpful under this misspecification. The matched-family positive control gives adaptive versus uniform soft changed-node MSE 0.02839 versus 0.26823, but does not rescue the held-out gate.

Custody: 40 source receipts cover **48,000** source training responses. Eighty target setting receipts cover **32,000** target arm-response counts; the sum of within-cell acquired unions is 20,682 prefixes, and the global union across source-size arms and settings is **10,988** acquired response identities. There are 14,400 node-method rows. Every source-data, posterior, acquired-response, action, system, evaluation-design, metric, and suite hash was checked. A full rerun was byte-identical. The independent validator recomputed all 14,400 scores from stored acquired rows and source posteriors, with the held-out term included in the private conditional mean. NumPy emitted matrix-operation warnings during generation on this host, but all arrays and scores were finite and an independent contraction agreed to machine precision on checked systems. No CURC job or closed-model call was used for this short numerical run.

The result supports a narrow acquisition gain on this matched simulator while rejecting the proposed safe transfer architecture at the frozen gate. Do not expand the same top-eight/mixture rule on these systems. A next C model needs explicit representation of the held-out form or a calibrated residual expert, together with untouched-node protection.
