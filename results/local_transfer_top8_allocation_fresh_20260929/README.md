# Fresh top-eight transfer allocation (29 September 2026)

The [protocol](../../docs/development/guidance/protocol_transfer_top8_allocation_fresh_2026-09-28.json) was frozen at `4f014730` and code at `72886204` before generating systems 800–819. Each policy acquires four target responses on every node, then either spends the remaining 80 uniformly or gives ten more responses to each of the eight nodes with the strongest scratch-versus-source evidence. The model fit uses the same fixed 0.1-prior soft mixture as the prior fresh study. The setting is k=1 family or coefficient change, 30 nodes, with 16 or 64 separately acquired source responses per node.

**The complete frozen point gate fails in two of 16 contrasts**, both in the 16-source-example coefficient arm. Changed-node MSE for adaptive soft mixture divided by uniform soft mixture is 0.030/0.036 for family changes at source sizes 16/64, and 0.226/0.188 for coefficient changes. The 20-system paired bootstrap 95% intervals for these four ratios are [0.015, 0.071], [0.018, 0.082], [0.101, 0.426], and [0.078, 0.387]. The changed node lands in the top eight in 20/20, 20/20, 19/20, and 20/20 cases, respectively.

The failed 16-source coefficient contrasts matter: adaptive soft mixture is **1.116×** adaptive scratch on changed nodes (gate ≤1.05), and **1.102×** uniform soft mixture on unchanged nodes (gate ≤1.05). The latter paired interval is [1.028, 1.184]. At source size 64, the corresponding ratios are 1.001 and 1.014, within the point limits. Full per-seed means, rank hits, all 16 contrasts, and paired intervals are in `analysis/`.

The large changed-node gain is mainly from **where the target responses are spent**. Adaptive scratch divided by uniform scratch changed-node MSE is 0.036 for family changes and 0.184/0.165 for coefficient changes at source sizes 16/64. Adaptive soft mixture is approximately equal to adaptive scratch for family changes. This supports a numerical acquisition capability on this matched synthetic setting; it does not establish a special advantage from a reusable foundation-model mechanism.

Custody: 40 source cells contain 48,000 counted source training responses. There are 80 target setting cells; each adaptive and uniform policy arm receives exactly 200 target responses, totaling 32,000 arm-response counts. Because the simulation shares target prefixes, the union of acquired prefixes is 20,693 responses. The simulator pre-generates 420 potential responses per setting (33,600 across cells), but policies fit only their acquired prefixes. All source data and posterior hashes, target action/metric hashes, counts, finite scores, and deterministic replay matched. No CURC job or closed-model API call was used for this short local run.

This is a prospectively frozen 20-system synthetic result for one top-eight rule. The matched six-feature generator makes change ranking unusually easy, and the primary gate fails. The next test needs an explicit harder mechanism family and an untouched-node protection strategy; tuning top-eight or mixture parameters on these systems would not provide independent confirmation.
